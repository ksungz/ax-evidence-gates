# MRT API Doctor

## 문제

마이리얼트립 Open API는 서비스마다 페이지 시작 번호와 응답 필드가 다릅니다. 항공 검색은 파라미터 이름과 실제로 넣어야 하는 코드의 의미가 다르고, 인증 형식이나 링크 길이 제한도 여러 문서에 나뉘어 있습니다.

이런 차이는 코드를 작성할 때 놓치기 쉽고, 실행한 뒤 빈 결과나 오류를 보고 나서야 원인을 찾게 됩니다.

## 사용자

마이리얼트립 Open API 또는 MCP를 제품에 연결하는 개발자가 코드 작성과 리뷰 단계에서 사용할 수 있도록 만들었습니다.

## 선택한 범위

실제 상품을 검색하거나 예약하는 앱을 만들지 않았습니다. 공개 개발자센터에서 직접 확인할 수 있는 페이지 기준, 공항 코드, 인증, 호출 제한, 링크 길이 같은 연동 실수 10가지만 검사합니다.

문서에서 확인할 수 없는 내부 동작은 추측하지 않고 검사 범위에서 제외했습니다.

## 구현

- Python, JavaScript, TypeScript 등의 연동 코드를 읽는 정적 검사기
- 공개 문서에서 정리한 10개 규칙
- 각 발견 항목에 수정 방향과 문서 원문 인용 연결
- 문서가 바뀌었는지 다시 확인하는 인용 검증기
- API 키 없이 실행하는 공개 MCP 상태 확인
- 나쁜 연동 코드와 수정된 코드 예제

## 검증

연동 코드 검사 14개와 문서 인용 검증 5개, 총 19개 테스트를 작성했습니다. 잘못된 예제에서 오류와 경고를 찾고, 수정된 예제에서는 발견 항목이 없는지 확인했습니다.

## 한계

규칙 기반 정적 검사라 잘못 잡거나 놓칠 수 있습니다. 실제 API 키, 상품 데이터, 예약과 결제 정보는 사용하지 않으며 마이리얼트립의 공식 도구도 아닙니다.
