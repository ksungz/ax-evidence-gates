# Investment Answer Gate

## 문제

초보 투자자의 불안에 답하는 과정에서 "지금 매수", "수익이 확실" 같은 단정 문장이나 손실 가능성과 거래 제한을 빠뜨린 설명은 잘못된 확신을 줄 수 있습니다.

## 사용자

금융 관련 상담·안내 답변 템플릿, FAQ, UX 문구와 회귀 테스트 fixture를 검수하는 개발자와 QA 담당자를 대상으로 설계했습니다.

## 선택한 범위

추천 챗봇을 만들지 않고, 공개 자료를 기준으로 답변 초안에 필요한 확인 과정과 위험 설명이 있는지 점검하는 로컬 도구로 범위를 좁혔습니다.

## 구현

- Markdown과 JSON 입력
- 직접 매수·매도 권유 탐지
- 수익 보장 또는 손실 축소 표현 탐지
- 투자 목적, 기간, 보유 여부와 손실 감내 가능성 누락 확인
- 공개 근거 URL, 원금 손실, 시세·체결 불확실성과 거래 제한 설명 확인
- Markdown 또는 JSON finding 리포트

## 검증

8개 테스트가 위험 문구, 사용자 조건 누락, 공개 근거 누락과 주문장애·시세 지연·소수점 거래 제한별 설명을 확인합니다. 개선된 샘플 답변은 finding 0건으로 통과합니다.

## 제출 이후 확장

해커톤 제출 이후 finding을 출력하는 도구에서 검수자가 실제 결정을 내리는 업무 흐름으로 확장했습니다.

- 기존 게이트를 LangGraph 검사 노드로 재사용
- Finding이 있으면 사람 검토 단계에서 실행 중단
- 승인, 수정, 반려 결정 기록
- 수정본 재검사
- 단계별 감사 로그
- Streamlit 검토 화면

이 기능은 원래 제출물에 포함되지 않은 `v0.2 Post-hackathon iteration`입니다.
