# Commerce Listing Preflight

## 문제

상품 등록 데이터의 속성 누락, 태그 불일치와 사이즈 이상치는 등록 반려뿐 아니라 사용자 탐색 품질에도 영향을 줄 수 있습니다.

## 사용자

상품을 등록하는 입점 브랜드 담당자와 등록 데이터를 다루는 개발자가 등록 전에 사용할 수 있는 로컬 검수 도구로 설계했습니다.

## 선택한 범위

실제 무신사 어드민이나 내부 스키마를 재현하지 않습니다. 상품정보제공고시, 공개 상품 페이지 표시 항목과 무신사가 공개한 택소노미 사례를 바탕으로 별도의 검수용 JSON 포맷을 선언했습니다.

공개 문서에서 확인할 수 있는 의류 고시 9개 항목, 상의 실측 4개 항목과 용어 사례 6개 그룹만 다룹니다.

## 구현

- 필수 필드와 상품정보제공고시 누락 검사
- 소재 비율과 사이즈 단위·역전값 검사
- 제한된 공개 사례 기반 태그·용어 검토 신호
- 입력 위치, 원문, 공개 근거와 수정 제안을 포함한 JSON 리포트
- 리포트 JSON Schema 검증

## 검증

17개 테스트가 정상 샘플, 속성 누락, 태그 불일치, 사이즈 역전, 고시 누락, 잘린 JSON과 잘못된 타입을 확인합니다. 모든 finding에 공개 근거가 없으면 리포트 검증이 실패합니다.

## 한계

이미지 분석, 자동 상품 등록, 가격·재고·옵션과 실제 반려 사유는 다루지 않습니다. 공개 사례 밖의 용어와 상의 외 카테고리는 판단하지 않습니다.
