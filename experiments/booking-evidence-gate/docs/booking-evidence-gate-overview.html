Booking Evidence Gate for MyRealTrip TNA

AI 여행 답변이 사용자에게 나가기 전에 예약 가능 여부, 가격, 즉시확정, 포함사항, 취소 가능 여부 같은 구매 관련 문장이 충분한 근거를 갖는지 확인하는 재현 가능한 품질 게이트입니다.

역할 추천 생성이 아니라 사전 검수
데이터 Synthetic fixture와 공개 문서 기반 field만 사용
실행 로컬 script, tests, Codex skill demo

해결하는 문제

여행 AI는 자연스러운 추천 문장을 만들 수 있지만, 구매 직전 표현에는 날짜별 예약 가능 여부, 옵션 가격, 즉시확정, 포함/불포함, 취소 가능 여부 같은 근거가 필요합니다.

이 플러그인은 이미 생성된 답변이 근거 없이 구매 확신을 주는지 확인합니다. 실제 예약, 결제, 실시간 재고 조회는 구현하지 않습니다.

현재 프로토타입의 경계

  • 실제 MyRealTrip 내부 데이터나 비공개 API를 사용하지 않습니다.
  • 샘플 answer contract, synthetic TNA evidence, claim policy로 재현합니다.
  • 취소정책 field는 현재 공개 TNA fixture 범위에 없으므로 관련 claim은 BLOCKED입니다.

입력 구조

Answer Contract

검수할 AI 답변 claim

claims[]에 문장 span, claim type, 날짜, 옵션, 가격, evidence pointer를 담습니다.

  • src/contracts/answer_contract.example.json
  • src/contracts/try_in_chat_review.example.json
Synthetic TNA Evidence

공개 문서 기반 샘플 근거

문서에서 확인되는 TNA endpoint와 field를 synthetic fixture로 구성합니다. 라이브 재고나 실시간 가격이 아닙니다.

  • src/fixtures/synthetic_tna_evidence.json
Claim Policy

판정 기준

예약 가능, 가격, 즉시확정, 포함사항, 취소정책 등 claim type별 필요한 evidence 기준을 명시합니다.

  • src/policies/claim_policy.json

처리 흐름

1. Claim 분류

답변 안의 구매 관련 문장을 availability, option_price, instant_confirm, included, cancellation_policy 같은 type으로 다룹니다.

2. Evidence path 확인

claim이 지정한 JSON pointer를 fixture에서 해석하고, 필요한 field와 claim 인자가 일치하는지 확인합니다.

3. Verdict 생성

각 claim에 SUPPORTED, CONDITIONAL, BLOCKED를 부여하고, span, reason, evidence path를 결과에 포함합니다.

판정 기준

SUPPORTED

필요한 evidence path가 존재하고, claim의 날짜, 옵션, 가격, 수량 같은 인자와 일치합니다.

CONDITIONAL

근거가 일부 있거나 간접적이어서 사용자에게 단정 표현 대신 조건이나 주의 문구가 필요합니다.

BLOCKED

필요한 근거가 없거나, 공개 fixture 범위에 없는 정보를 단정합니다. 구매 판단에 영향을 주는 표현은 수정해야 합니다.

Try Chat 데모 핵심

2026년 5월 1일 오사카 여행에서 간사이공항에서 난바로 이동한다면 라피트 편도 티켓을 추천합니다.
해당 날짜에 바로 예약 가능하고, 결제하면 즉시 확정됩니다.
성인 1명 기준 가격은 12,000원이며, 수하물 포함이고 무료 취소도 가능합니다.

예약 가능, 즉시확정, 12,000원 가격, 수하물 포함은 샘플 evidence와 일치합니다. 하지만 "무료 취소도 가능합니다"는 현재 synthetic TNA evidence와 claim policy 안에 취소정책 근거가 없으므로 근거 부족으로 잡힙니다.

데모 출력 요약

전체 판단: 수정 필요
요약: 근거 있음 4개, 확인 필요 0개, 근거 부족 1개
- 근거 있음: 해당 날짜에 바로 예약 가능
- 근거 있음: 결제하면 즉시 확정됩니다
- 근거 있음: 성인 1명 기준 가격은 12,000원
- 근거 있음: 수하물 포함
- 근거 부족: 무료 취소도 가능합니다
  이유: 제공된 근거 데이터에는 취소 정책 근거가 없습니다

실행 명령

python3 src/scripts/readiness_audit.py \
  --answer src/contracts/try_in_chat_review.example.json \
  --evidence src/fixtures/synthetic_tna_evidence.json \
  --policy src/policies/claim_policy.json \
  --format korean-summary

테스트 명령

python3 -m unittest discover -s src/tests -v

테스트는 예약 가능, 근거 없는 예약 가능, 상대 날짜, 검색 대표가, 취소정책, 예약/결제 완료 claim, 수량 초과, verdict trace, 사용자 표시 문구를 확인합니다.
